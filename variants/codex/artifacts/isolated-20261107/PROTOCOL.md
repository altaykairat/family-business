# Изолированные модельные исполнители — пилот 07.11.2026

Новая инструкция Алтая в текущем чате разрешает разработчику запускать независимых саб-агентов вместо ручного переноса промптов. Это заменяет прежнее ограничение брифа для этого эксперимента. Общие документы команды не меняются.

Факторы: модель (gpt-6-luna / gpt-6.1-terra) × декомпозиция (монолит / секции). Оба диалога проходят все четыре условия. Усилие medium, fork_turns=none. Один новый агент на один промпт, без повторного использования чата для следующей секции или диалога. Родитель получает только пути результатов, затем алгоритм проверяет файлы. История главного чата не передаётся. Агенты инструктированы читать только один входной файл и писать только один ответ; техническая файловая песочница между ними отсутствует.

Данные: p1-ru-012 и p1-kz-008, намеренно выбранная диагностическая пара из ранее подготовленной выборки. Предварительно зарегистрировано 20 заданий в jobs.json: 4 монолитных + 16 секционных. Это пилот инфраструктуры и обнаружения неоднозначностей, не репрезентативный тест качества. Пока один повтор на условие, нет EN/звонков. Не делать вывод о качестве на всём DEV.

Не исправлять/подгонять ответы. Отклонённые валидатором результаты сохранять. Не приписывать точные usage или API latency: инструмент делегирования их не возвращает. Нельзя считать отсутствующий ответ нулевой оценкой или считать неполную оценку нормализованным итогом.

Токены: общий локальный токенизатор/эвристика отдельно для каждого входного промпта и видимого JSON. Цена: опубликованные Standard input/output без кеша; источник/дата в comparison.json. Это частичный API-эквивалент, не списание за Codex. Скрытые reasoning-токены, системный контекст и инструменты недоступны; показать сценарий добавочных 1000 reasoning-токенов на вызов. Скорость разработки/очереди агента не выдавать за latency модели.

Основные проверяемые гипотезы: H1 — независимые секции меняют суждения относительно монолита; H2 — рост расхода оправдывается уменьшением человечески подтверждённых ошибок; H3 — Luna+выборочная Terra-проверка может быть дешевле полного Terra. H1 можно описать сейчас через расхождения; H2/H3 требуют человеческого эталона и следующего этапа. Согласие моделей не заменяет эталон.

Для продолжения: человек независимо заполняет human-review-blank.json; после этого считаем accuracy по критериям, macro, no/na confusion, total MAE, evidence validity/overlap, стоимость исправленной ошибки, ошибки на $1. Сравнения парные по одинаковым диалогам, доверительные интервалы кластеризованы по диалогу. На более широком наборе выделить закрытый hold-out до настройки промпта. Дополнительные абляции: с/без признаков, blind/anchored review, medium/high, новые независимые повторы.

Research statement: «Как распределение ограниченного inference-бюджета между моделью и независимой декомпозицией влияет на качество и проверяемость многоязычной QA-оценки?» Результат пока пилотный, без заявления прироста точности.
