## Итог в трёх строках

1. Пайплайн итерации 1 превращён в **платформу**. Она хранит историю событий, версии, апелляции, эталон и метрики, ведёт цикл обучения и аналитику по людям. Всё доступно через **HTTP API из 86 команд** — по одной на каждую кнопку из таблицы MC. Стек — Python 3.9 без зависимостей.
2. **Проходят все 46 тестов**: старые, новые сквозные тесты платформы и тесты Antigravity; тесты Codex тоже зелёные. Цепочка хешей истории цела.
3. Проведён **эксперимент «субагенты вместо API»**: 140 изолированных вызовов. По нему **V1 на Sonnet 5.5** выгоднее декомпозиции по критериям: около $0.05 за диалог против $0.17, точность пока не ниже. Пока это предварительный вывод — человеческого эталона ещё нет.

## Эксперимент: сколько вызовов LLM на подзадачу

**Как проводили.** Каждый промпт отправлялся отдельному изолированному субагенту — это замена API-вызова. Выборка: 5 диалогов: `p1-ru-012`, `p1-ru-022`, `p1-kz-008`, `p1-en-015` и звонок `p4-ru-001`. Шаблон один и тот же, менялись только декомпозиция (V1 / V2 / V3) и модель. Всего 140 вызовов, все ответы валидны. Цена посчитана как эквивалент API Anthropic.

| Конфигурация | Вызовов / диалог | $ / диалог | $ / 65 диалогов | $ / 10 контрольных | Прокси-точность |
|---|---|---|---|---|---|
| V1 Haiku 5.5 | 1 | 0.004 | 0.23 | 0.04 | 80.0% |
| V3 Haiku 5.5 | 8 | 0.011 | 0.72 | 0.11 | 80.0% |
| **V1 Sonnet 5.5** | **1** | **0.052** | **3.37** | **0.52** | **97.5%** |
| V2 Sonnet 5.5 | 4 | 0.106 | 6.88 | 1.06 | 92.5% |
| V3 Sonnet 5.5 | 8 | 0.167 | 10.86 | 1.67 | 92.5% |
| V1 Opus 5.5 | 1 | 0.107 | 6.92 | 1.07 | 90.0% |

**Выводы:**

- **Модель важнее декомпозиции.** Haiku → Sonnet даёт +15–20 п. п. за +$3 на весь DEV.
- **Отдельный вызов на каждый критерий (V3) не окупился.** Он втрое дороже V1, а прироста нет.
- **Стабильность Sonnet V1 высокая:** два независимых прогона совпали в 97,5% решений.
- **Конфигурации расходятся ровно на спорных трактовках:** шкала `c06`, «Нет» ↔ N/A в `c02` / `c07`, ступень `c04`.
- **Одно расхождение «Нет» ↔ N/A сдвигает итог на ~16 баллов.** Для сравнения по итоговому баллу это главный риск.
- **Грубую ошибку в `p1-ru-022` нашли все конфигурации.**

**Ограничения:**

- **Прокси — это не точность.** Это совпадение с большинством остальных конфигураций: в нём заметное смещение в пользу Sonnet, а 2,5 п. п. — одно решение из 40.
- **Стоимость занижена.** Токены размышлений моделей не видны, а по API они оплачиваются.
- **Изоляция субагентов неполная.** Они видят системный промпт Claude Code и файл памяти проекта.
- **Расход подписки примерно в 12 раз больше эквивалента API.**

Полный отчёт с расхождениями по каждому решению — [runs/sa_v1/reports/experiment_calls.md](../../runs/sa_v1/reports/experiment_calls.md). ## Как проверить

```bash
python3 -m unittest discover -s tests       # 46 тестов
python3 -m cqa commands                     # контракт API
python3 -m cqa serve                        # HTTP API: http://127.0.0.1:8765/api/v1/commands
python3 -m cqa history.verify               # цепочка хешей истории
python3 -m cqa conversation.card conversation_id=p1-ru-012
```

Тесты платформы — [tests/test_platform.py](../../tests/test_platform.py). Они идут во временном рабочем каталоге и не трогают реальную историю. Проверяют:

- путь апелляции с правами и правилами типов;
- слепой режим;
- предложения, версии, активацию и откат;
- замену критерия с предпросмотром;
- эталон и метрики, подделку истории, машину времени, аналитику;
- HTTP-ответы 403 / 405 и заголовки CORS.

## Что осталось и ограничения

- **HTTP-провайдер** (API или локальная модель) пока только описан контрактом.
- **Подразумеваемые веса регрессией** не сделаны: нет данных. Общая оценка проверяющего уже собирается в поле `overall_score`.
- **Прецеденты в промпт** попадут, только когда в шаблоне появится `{{PRECEDENTS}}` (это зона сессии дизайна).
- **Ид апелляций и решений** выдаются по счётчику. Одновременные запросы нескольких пользователей могут конфликтовать; для демо это не проявляется.
- **Интерфейс** не делался — по заданию, у владельца проекта свои идеи.

## Что нужно от команды

1. **Эталон.** Запустить `gt.draft` по трём агентам прогона `r001` (или по пилоту `sa_*`) и разрешить расхождения людьми. После этого `experiment_calls.py --gold` и `metrics.compare` дадут настоящую точность вместо прокси.
2. **Ответы на вопросы к дизайну** ([implementation.md → Вопросы к дизайну](implementation.md#вопросы-к-дизайну)):
   - что публикуем для сдачи — ансамбль или одну модель;
   - HEAD = v1 до первой активации;
   - нужен ли отдельный профиль для звонков;
   - порог регрессии;
   - формат эталона.
3. **Предложения другим зонам** ([implementation.md → Предложения другим](implementation.md#предложения-другим)):
   - плейсхолдер `{{PRECEDENTS}}` и шаблоны задач оркестратора — в `prompts/templates/`;
   - строки запуска платформы — в корневой README;
   - Antigravity и Codex: их результаты уже сравниваются платформой — достаточно поля `checklist` и `usage` в результатах.
