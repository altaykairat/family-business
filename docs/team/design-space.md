# Пространство дизайна: параметры, факторы, протоколы

> Стадия: **дизайн пайплайна**. Цель документа — собрать **максимум** ручек, которые можно крутить, чтобы потом экспериментами отсеять лишнее. Ничего из этого пока не решено окончательно, если не помечено ✅.
>
> Контекст и обоснования — в [discussion.md](discussion.md). Этапы S0–S10 — оттуда же (ось А). Варианты декомпозиции V1–V5 — ось Б.

**Как читать таблицы.** `ID` — короткий код параметра для ссылок в экспериментах и конфигурации. «Старт» — значение, с которого предлагаю начать (не финальное). Пометки: ✅ — решено, 🧪 — кандидат в эксперимент, ⚠️ — риск / тонкость.

---

## 0. Сквозные принципы (решено)

- ✅ Каждый этап: вход-файл → выход-файл, любой артефакт можно открыть, поправить и перезапустить пайплайн с этого места.
- ✅ Все параметры ниже живут в версионируемой конфигурации; в коде нет захардкоженных значений.
- ✅ Подсчёт балла (S7) — отдельная функция, без LLM. Смена весов пересчитывает итоги без повторных вызовов модели.
- ✅ Веса меняет админ; оркестратор только предлагает с обоснованием.
- ✅ Апелляции типизируются (A–D), решение проверяющего — ground truth.
- ✅ На время разработки LLM заменяют облачные агенты (Claude Code, Codex, Antigravity/Gemini) через файловый адаптер; к ~16–18 ч — API или локальная модель.
