# Свод трактовок для разметки

> Спорные места чек-листа, где возможны два ответа. Решение принимает Алтай по ходу разметки; помощник в чате ведёт свой нумерованный свод (R1, R2, …) — после разметки перенесите его сюда (команда «Свод» в чате). Каждое правило — это и уточнение для эталона, и кандидат в уточнения промпта (механизм B, «выжимка правил»). Всё в рамках выданного чек-листа: правила уточняют формулировки, а не добавляют критерии.
