# Параллельная работа: кто что делает

Над репозиторием одновременно работают несколько сессий и агентов. Чтобы не мешать друг другу, у каждого своя зона.

| Кто | Роль | Зона (что меняет) | Задание |
|---|---|---|---|
| **Claude Code — сессия дизайна** | Дизайн пайплайна: обсуждения, решения, каталог параметров, протокол экспериментов, шаблоны промптов | `docs/team/discussion.md`, `docs/team/design-space.md`, `docs/team/plan.md`, `docs/team/agent-briefs/`, `prompts/templates/` | — (эта сессия) |
| **Claude Code — сессия реализации** | Реализация платформы: ядро пайплайна, хранилище, история, версии, апелляции, интерфейс для будущего фронтенда | `cqa/`, `scripts/`, `tests/`, `config/`, `docs/team/pipeline.md`, `docs/team/implementation.md` | [claude-implementation.md](claude-implementation.md) |
| **Antigravity** | Альтернативные прототипы: «мелкая декомпозиция» | `variants/antigravity/`, `docs/team/variants/antigravity.md`, свои шаблоны и прогоны | [antigravity.md](antigravity.md) |
| **Codex (ChatGPT)** | Альтернативные прототипы: «проверка, маршрутизация, гибрид» | `variants/codex/`, `docs/team/variants/codex.md`, свои шаблоны, конфиги и прогоны | [codex.md](codex.md) |

## Общие правила для всех

1. **Материалы организаторов не меняются:** `docs/organizers/`, `data/dev/raw.json`, `data/checklists/default/v1.json`.
2. **Свою зону меняешь свободно, чужую — нет.** Если нужно изменение в чужой зоне, опиши его в своём документе (раздел «Предложения другим») — владелец зоны решит.
3. **Общий рабочий каталог.** Не переключай ветки, не делай `reset`, `checkout` чужих файлов, `stash`, `push --force`. Коммить только свои файлы явно (`git add <свои пути>`), не `git add -A`.
4. **LLM-вызовы в рантайме сейчас не делаются.** Обработку промптов выполняет человек вручную в новых чатах облачных моделей. Ни одна сессия и ни один агент не изображает LLM и не обрабатывает промпты прогонов сам — задача агентов только в разработке.
5. **Решения команды обязательны** — `docs/team/discussion.md`, раздел «Решения» (1–21). Не согласен — аргументируй в своём документе, не обходи молча.

## Обновление 2026-11-07: новые материалы организаторов — касается всех

Прочитай [docs/organizers/results-format.md](../../organizers/results-format.md), [docs/organizers/announcements.md](../../organizers/announcements.md) и разбор в [discussion.md, «Обсуждение 2»](../discussion.md#обсуждение-2-новые-материалы-организаторов-формат-сдачи-отбор-демо). Коротко:

- **Сдача** — `results/dev/results.json` (65 диалогов) и `results/prod/results.json` (10 контрольных чатов) в формате JSON 1.0 с кодами критериев организаторов. Папка `results/` — общая: туда пишет только экспортёр платформы, финальную версию коммитит Алтай.
- **Контроль — 1 час** на 10 чатов, включая получение, оценку, проверку и push. В своём документе указывай для варианта число LLM-вызовов на 10 диалогов и оценку времени (метрика M.16).
- **Отбор без формулы:** близость к GT «в целом», обоснованность, разумные N/A и грубые ошибки, **не придумывать факты**, воспроизводимость; техническая проверка репозитория; удобство; разнообразие подходов (локальные / облачные / гибрид).
- **Защита — живое демо:** диалоги с грубыми ошибками и почему; апелляция от оператора; добавить / изменить критерий и вес; результат диалога с обоснованием. Жюри может само поработать с системой.
