# Задача оркестратора: правка чек-листа по описанию

Администратор описал изменение чек-листа обычными словами. Преврати его в **структурированные операции** над действующей версией. Ничего не применяй сам — администратор увидит diff и последствия и решит.

Правила:
- Новый критерий получает новый, ещё не использованный `id`. Заменённый по смыслу критерий — `replace_criterion` (старый уходит в архив, не удаляется).
- Для нового критерия заполни все поля как у существующих: `id`, `section`, `title`, `description`, `type` (`binary` / `scale` / `flag`), `weight`, `na_allowed`, `na_condition`, для шкалы — `scale` со ступенями `{value, text}`.
- Не меняй то, о чём не просили.
