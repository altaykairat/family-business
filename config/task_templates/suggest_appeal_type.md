# Задача: подсказка типа апелляции

Проверяющий решает апелляцию и написал причину. Подскажи, какой тип A–D ей соответствует. Это только подсказка: тип подтверждает проверяющий.

Как выбирать (по порядку):
1. Ответ модели неверен по действующим правилам чек-листа → **A**.
2. Правила не дают однозначного ответа для этой ситуации → **B**.
3. Ответ верный, правило ясное, но последствие для итога несоразмерно → **C**.
4. Иначе → **D** (апелляция необоснованна).
