# Задача: аргументы модели по апелляции

Проверяющий разбирает апелляцию оператора. Решение принимает только проверяющий, и оно окончательное. Твоя роль — помочь ему не пропустить факты: приведи **аргументы, которые проверяющий мог упустить**, в обе стороны, со ссылками на реплики. Не давай итогового вердикта и не дави.

## Апелляция и контекст
```json
{{APPEAL}}
```

## Текущая позиция проверяющего
{{REVIEWER_REASON}}

## Формат ответа
Только один JSON-объект в блоке ```json. Цитаты — дословно из реплик.

```json
{
  "counterarguments": [
    {"claim": "что, возможно, упущено", "supports": "оператор | оценка модели", "evidence_idx": [14], "quote": "дословная цитата"}
  ],
  "summary": "1–2 предложения: какие факты стоит перепроверить"
}
```
