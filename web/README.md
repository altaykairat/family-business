# Freedom Quality — интерфейс платформы

Запуск из корня репозитория:

```sh
python3 -m cqa serve
```

Открыть http://127.0.0.1:8765. Установка npm-пакетов и сборка не нужны: HTML, CSS и JavaScript без зависимостей. Шрифт Manrope загружается из Google Fonts; без интернета используется Arial.

Все данные и действия идут через API платформы (`/api/v1/<команда>`, POST с JSON и заголовком `X-CQA-Actor`). Демонстрационные показатели не подставляются.

## Разделы

- **Обзор** — средний балл, покрытие оценкой, грубые ошибки, открытые апелляции, языки. Карточки показателей кликабельны и открывают отфильтрованный список.
- **Диалоги** — поиск, фильтры языка и канала, вкладки «Оценены / Грубые ошибки / С апелляцией», пагинация, экспорт CSV.
- **Карточка диалога:**
  - расшифровка; клик по реплике выбирает её для апелляции;
  - итог, разделы, ответ по каждому критерию с объяснением модели и цитатами (номер реплики — переход к ней, отметка совпадения цитаты), уверенность, нехватка данных, рассуждение;
  - решения проверяющих «было → стало» с типом и причиной;
  - **«Откуда ответ»** — версии, текст промпта, сырой ответ модели, действия людей;
  - **«Оценить диалог»** (администратор, руководитель) — промпт собирается по активному чек-листу; кто оценивает, выбирается кнопкой:
    - **ChatGPT · Codex** — новая сессия без контекста вместо API-вызова: пустая временная папка вне репозитория, без инструментов и истории, у Codex — пустой `CODEX_HOME` (без глобального AGENTS.md); ответ возвращается сам, проверяется, оценивается и публикуется (обычно 1–3 минуты);
    - **Вручную** — скопировать промпт в любой чат и вставить ответ.
    Непрошедший проверку ответ не сохраняется, ошибки показываются. Настройки агентов и пути к программам — `config/providers.json`.
- **Апелляции** — список с решениями; клик открывает карточку на нужном критерии.
- **Операторы** — статистика по опубликованным оценкам.
- **Чек-лист** — версии (активна / черновик / заменена), просмотр любой версии. Администратор: «Изменить чек-лист» (названия, формулировки, веса, тип, N/A, ступени шкалы, новый критерий, архив вместо удаления) → новая версия-черновик → «Активировать и пересчитать» (оценки пересчитываются без вызова модели; если у новых критериев нет ответа, система сообщает, сколько диалогов нужно оценить моделью).

## Разделы платформы (добавлено к сайту)

- **Очередь проверки** — ответы модели с нехваткой данных, неоднозначностью или низкой уверенностью (сначала самые сомнительные) и апелляции, ждущие решения; клик открывает карточку на нужном критерии.
- **Цикл обучения** — пять шагов цикла; «До и после» по сохранённым отчётам (совпадение, ошибка итога, ±5, исправлено / сломано по критериям); закономерности с уверенностью и порогами (окно: с активации текущей версии — то, что видит оркестратор, или вся история); «Симулировать проверяющего» и «Проанализировать историю» (оркестратор — Codex в новой сессии); предложения с «Принять → новая версия» / «Отклонить»; регрессионные проверки.
- **Точность** — источник × эталон × часть (все / test / tune): совпадение меток с ДИ, MAE итога, грубые ошибки, валидность доказательств, полосы по критериям, список расхождений.
- **Оценка и сдача** — загрузка набора из API организаторов по `group_id` (`.env → CQA_API_URL`) или из JSON; **оценка набора в фоне** (`job.evaluate`: сборка промптов по активному чек-листу → параллельные сессии Codex без контекста → проверка → публикация → по желанию выгрузка `results/<набор>`), прогресс и журнал задания; выгрузка и проверка `results/dev` / `results/prod`.

Для контрольного набора: загрузить `group_id` → «Оценить в фоне» с выгрузкой в `results/prod` → дождаться «готово» → commit и push.

## Агенты вместо API

Сейчас включён только **ChatGPT · Codex**; Claude Code и Antigravity настроены, но выключены в `config/providers.json` (`enabled: false`) — включаются одной правкой.

| Агент | Как запускается | Что нужно один раз |
|---|---|---|
| Codex | `codex exec` из ChatGPT.app, `--sandbox read-only --ephemeral`, отдельный `CODEX_HOME` со ссылкой только на `auth.json` | вход в Codex / ChatGPT (уже есть) |
| Claude Code | `claude -p` из приложения Claude, `--tools "" --setting-sources "" --system-prompt …`, без сохранения сессии | войти в консольный Claude Code: запустить программу из `config/providers.json → claude-code` в терминале и выполнить `/login` |
| Antigravity | `antigravity-ide chat -n -m ask -a <промпт>` — новый чат в окне IDE | — |

Для пакетной оценки (например, всех 65 диалогов DEV) — командой, по одному промпту в новой сессии:

```sh
python3 -m cqa run.prepare run_id=r-base template=v2 agents=codex-cli
python3 -m cqa run.dispatch run_id=r-base agent=codex-cli provider=codex-cli
```

## Роли

Роль выбирается внизу бокового меню; права проверяет сервер, интерфейс только скрывает недоступные кнопки. Авторизации нет — это локальный прототип.

| Роль | Что может |
|---|---|
| Администратор `a-01` | всё: оценка диалога, решения по апелляциям, изменение и активация чек-листа |
| Руководитель `s-01` | оценка диалога и публикация |
| Проверяющий `r-01`, `r-02` | решение по апелляции: подтвердить или изменить, причина, тип A–D; отметить решение прецедентом |
| Оператор диалога | апелляция по критерию своей оценки с комментарием и ссылкой на реплику |

## Происхождение

Дизайн и структура страниц — новый сайт команды. Действия платформы (роли, апелляции, решения, ручная оценка, версии чек-листа, «Откуда ответ») встроены в него поверх API. Данные загружаются последовательно: команды аналитики перестраивают SQLite-проекцию, и параллельные запросы к ней конфликтуют. Если второстепенный раздел (аналитика) недоступен, сайт работает дальше и показывает уведомление.

Проверено в браузере на отдельном рабочем каталоге с оценками: фильтр грубых ошибок, апелляция оператора, решение проверяющего с пересчётом итога, прецедент, «Откуда ответ», ручная оценка (включая отказ на неполном ответе), изменение и активация чек-листа с пересчётом, ширина 1440 и 375 px.
